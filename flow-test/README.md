# Flow test paint

`flow-test-paint.png` is a 2048×2048 test paint for the Hyundai Veloster N TCR.

One stripe pattern (and one level magenta band) was laid over an arrangement of
the pieces, then each piece's share was put back where that piece really sits
on the sheet. `how-the-pieces-were-arranged.png` shows the arrangement: each
piece is attached to its neighbour along the longest edge link in the map.

On the car, look at whether the stripes and the magenta band carry on across
the edges between the driver's side (Piece 2), the rear bumper (Piece 5) and
the roof piece (Piece 4). Grey pieces had no link and were left out.

This branch only holds these files. It is not part of the app.
